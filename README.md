# 📧 Email Spam Detection

A deep learning-based email spam detection system that uses a **GRU (Gated Recurrent Unit) based RNN model** to classify emails as **Spam** or **Ham (Not Spam)**.

The project includes an interactive **Streamlit web application** where users can enter an email message and instantly receive a prediction.

## 🚀 Live Demo

🔗 **[Try the Email Spam Detector](https://email-spam-detection-lh3apeiuzjgtjzphzqtkdd.streamlit.app/)**

## ✨ Features

- 📧 Classifies emails as **Spam** or **Ham**
- 🧠 Uses a **GRU-based Recurrent Neural Network**
- 🔤 NLP-based text preprocessing
- ⚡ Real-time prediction
- 🖥️ Interactive Streamlit interface
- 🌐 Deployed using Streamlit Community Cloud

## 🧠 Model

The project uses a **GRU (Gated Recurrent Unit)** neural network for text classification.

### Processing Pipeline

```text
Email Text
    ↓
Text Cleaning
    ↓
Tokenization
    ↓
Sequence Conversion
    ↓
Padding
    ↓
GRU-based RNN
    ↓
Prediction
    ↓
Spam / Ham
```

🎯 Project Goal

The goal of this project is to demonstrate how Natural Language Processing and deep learning can be used to automatically identify potentially unwanted email messages.
